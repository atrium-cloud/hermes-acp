Initial release: an ACP v1 agent for Hermes Agent built on its `tui_gateway` backend, for Hermes 0.20.6 (`v2026.8.27`) and above.

## Supported ACP v1 surface

Agent methods (client → adapter):

| Method | Notes |
| --- | --- |
| `initialize` | Protocol version 1; capabilities below; auth methods from Hermes' provider catalog plus terminal `hermes-setup`. |
| `authenticate` | Validates the named provider has usable credentials in Hermes; no credential travels over ACP. |
| `session/new` | Creates a gateway session at an absolute `cwd`; `mcpServers` and `additionalDirectories` are rejected. |
| `session/list` | This adapter's sessions with a known `cwd`, offset-paginated. |
| `session/resume` | Subscribes to a stored session without replaying its transcript. |
| `session/load` | Subscribes and replays the transcript (title, user/agent/thought chunks, completed tool calls) before responding. |
| `session/fork` | Head-only fork of a tracked session into a new gateway session. |
| `session/close`, `session/delete` | Close tears down the live session; delete also removes the stored row. |
| `session/set_mode` | `default` / `dont_ask` (per-session approval bypass), corrected when the gateway keeps a global bypass. |
| `session/set_config_option` | `model` (provider/model, with the expensive-model confirmation as an elicitation) and `approval_mode`. |
| `session/prompt` | Text, image, and embedded-resource blocks; slash commands from the advertised catalog; `$/cancel_request` cancels the turn. |
| `session/cancel` | Interrupts the turn; the prompt ends `cancelled`. |

Client methods (adapter → client): `session/update`, `session/request_permission` (Hermes approvals, fail-closed), `elicitation/create` (Hermes clarify questions and the model confirmation; form elicitation only).

Session updates emitted: `agent_message_chunk`, `agent_thought_chunk`, `user_message_chunk`, `tool_call`, `tool_call_update` (with `rawInput`, `rawOutput`, `locations`, rendered diffs as text), `plan`, `current_mode_update`, `config_option_update`, `available_commands_update`, `session_info_update`, `usage_update`.

Capabilities advertised: `loadSession`; `sessionCapabilities.list/resume/close/delete/fork`; `promptCapabilities.image/embeddedContext`. Not advertised and not implemented: audio prompts, MCP passthrough, additional directories, breakpoint forks, fs/terminal proxying, steering. See docs/caveats.md.

## Transport

- `serve` mode (default) spawns `hermes serve --isolated` and connects to its WebSocket; `attach` connects to a running gateway URL. Configuration is by `HERMES_ACP_*` environment variables (src/constants.ts).
- A failed or never-started Hermes turn is a protocol error, never a clean `end_turn`; a dead gateway fails in-flight prompts before the adapter exits.
- Hermes is an external runtime dependency, resolved as `hermes` on PATH (or `HERMES_ACP_HERMES_BIN`); no version is checked at runtime, and `bun run drift` guards upstream changes.

## Distribution

One `hermes-agent-acp.zip` attached to the GitHub Release: the `hermes-agent-acp` executable (a bundled script that runs on Node 22+; on Windows invoke it as `node hermes-agent-acp`) with LICENSE and NOTICE. Not published to npm. The executable is not called `hermes-acp` because Hermes' own installer and `hermes uninstall` own that name on PATH for the upstream `hermes acp` launcher.

Requires Hermes Agent 0.21.4 (`v2026.9.21`) or above, verified against 0.21.5 (`v2026.9.24`). The floor rises from 0.21.3: 0.21.4 added a `client.capabilities` handshake this release sends at startup, and on 0.21.3, which lacks the method, startup fails with an error naming the floor. The adapter never locks Hermes to a version; it runs whichever `hermes` is on PATH.

## Approvals and clarify on Hermes 0.21.4+

- v0.1.2 never sent the handshake, so on Hermes 0.21.4 and later the gateway failed every server-to-client request without sending it: approvals never reached the client and the gated command was cancelled, and clarify questions were skipped.
- The adapter now sends `client.capabilities {server_requests: true}` right after `gateway.ready`, within the startup deadline. A failure there fails startup rather than surfacing later as a gateway exit.

## Token usage

- `PromptResponse.usage` now reports the turn's own tokens, as the SDK documents the field and as claude-agent-acp and codex-acp report it. v0.1.2 sent Hermes' session running totals, so a client summing turns overcounted.
- The per-turn share is the difference of Hermes' running `prompt`/`completion`/`total` counters between the submit and the turn's end, measured from the latest totals any frame reported (including turns Hermes ran on its own). When Hermes rebuilds the agent, which restarts its counters, the share is taken from the restart.
- `inputTokens` counts cached and uncached input together, and `cachedReadTokens`/`cachedWriteTokens` stay unset: the gateway reports Hermes' cache counts only as a rounded hit percentage.
- The `usage_update` context gauge is now also sent from the turn's final `message.complete`, ahead of the prompt response. Hermes stops its once-a-second usage ticker before that frame, so one-call turns previously sent no gauge and multi-call turns ended one call stale.
- Known limit: when a "Bot Chat" session's agent is rebuilt at turn start and the turn's totals outgrow the old ones, that turn is undercounted.

## Dependencies

- `@agentclientprotocol/sdk` 1.5.0 (schema v1.23.0): the tool call `name` this adapter already sends is now a stable field; the new unstable session notices are unused.
- vitest 5.0.2 and `@types/node` 26.6.3 (development only).

## Development

- `docs/refs.md` records a floor (0.21.4) and a verified release (0.21.5) instead of a pin. `bun run test:e2e:sprite` defaults to the verified release, and `bun run drift` also checks the handshake method.
- Verified against live Hermes 0.21.4 and 0.21.5 on 2026-09-27, the full e2e tier passing 28/28 on each.

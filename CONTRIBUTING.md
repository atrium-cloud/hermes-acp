# Contributing to `hermes-agent-acp`

External pull requests are not accepted. Only verified collaborators contribute directly to this repository.

The repository remains licensed under Apache 2.0. Anyone may fork and build on the project under that license. Keep the attribution notices from [NOTICE](NOTICE), and review [TRADEMARKS.md](TRADEMARKS.md) before using the project name or branding.

## Issues

Focused, actionable issues are welcome. Include the observed behavior, expected behavior, Hermes version, ACP client, relevant environment details, and reproduction steps.

## Security

Security reports are welcome. Use GitHub's private vulnerability reporting when available. Do not include secrets, tokens, cookies, `.env` contents, prompt contents, or private file contents in issues, screenshots, or logs.
